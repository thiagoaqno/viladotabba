# Faixa de aviso: reabrir o programa depois de atualizar o servidor

O atualizador baixa a tela nova, mas o servidor que roda é o velho até reabrir o programa: a carreira recusava o piloto real (pedia o nome) e o nível 150. Agora, depois de uma atualização que mexe no servidor, uma faixa vermelha fica no topo de toda tela até reabrir (`corrida-pc.js`). Conferido no servidor de teste que a carreira com o Norris no nível 150 cria normalmente.
