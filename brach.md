# Tiro da Galera: as vozes do rádio por classe

As 207 falas que o Thiago gerou estão no jogo: 23 anúncios × 3 variações em cada uma das três vozes novas.

| Arma principal | Classe pronta | Pacote |
| --- | --- | --- |
| Submetralhadora | Faxineiro | `sfx/voix_smg.js` (2,2 MB) |
| Fuzil de precisão | Atirador | `sfx/voix_sniper.js` (1,3 MB) |
| Escopeta | Arrombador | `sfx/voix_shotgun.js` (1,4 MB) |

- Cada pacote só é baixado quando alguém nasce com uma classe dessa arma. Fuzil de assalto e o resto continuam com a voz padrão.
- **Conferido:** a página continua sem erro de sintaxe, e a lista de vozes por classe (`VOZ_CLASSE`) traz as três.
